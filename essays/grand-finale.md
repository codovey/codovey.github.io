And so this is the end of Software Engineering, ICS 314. What have I done? That's enough lyric parodying for now. The question of, "What have I done?" still stands.


### Functional Programming
Functional programming focused a lot on sets of data. Looking back, I can see how it factored into the final project. For previous experience assignments, we had to take object data and sort it. My Typescript Playground kept crashing because I tried pasting the ENTIRE database, but at least now I know what not to do. With a little more time and brain power, the Manoa Study Spaces site, my group's final project, could have used some functional programming strategies to create a sort ammeneties filter.

### User Interface Frameworks
HTML was my favorite thing ever and the only section where I completed both WODs. Free Code Camp is such a delight for learning HTML and CSS. Making a cute cat picture gallery website? Yes, please! Bootstrap, React, and Next.js proved to be far more of a challenge. Bootstrap has more specific containers and ids to make every color, text, icon, and box fit perfectly together. Remembering every little thing would be difficult, so I'm glad the assignments had some helpful guides on which type of navbar style and containers to use. Unfortunately, I couldn't get much practice with React or Next.js due to my Postgresql installation hating me for weeks. As of writing this essay, I'm going to have to try Digits again for the full Next.js practice experience.

### Development Environments
In this course, we mainly used two environments, Typescript Playground and VSCode. In a previous essay, I mentioned using Typescript felt much nicer than the super organized and class-filled Java. Typescript Playground was a nice website where you could type any kind of code without having to blow up your entire laptop... unless you imported an entire database list of text while trying to code. Typescript Playground is so cool that I was able to calculate a complicated math problem with a few lines of code. Yay for me! No new files or repositories, just code. Five stars. I thought VSCode was cool, too, aside from my previous (and constantly mentioned) Postgresql issues.


Did I learn a lot in this class? Not as much as some of my classmates due to my slight laziness, but for my own benefit, yes I did. Experience is the whole point of the class, and experience is what I got. I went through a real test of patience and had LOTS of practice over the course of the semester. I benefitted from this class in many ways, and I appreciate all the help I got from my classmates and amazing TA.
