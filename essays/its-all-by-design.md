# What in the World are Design Patterns!?
I spent way too long trying to understand what design pattenrs are that I ended up not completing this essay by the time I should have. Design patterns seem to be bits of code that can help you with various tasks. The concept of design patterns is just giving your code special names. Math like x + y? That's called Module Pattern. Objects and classes? Flyweight Pattern. The list goes on, but these are a couple I found the most simple.

There's also something called Island Architecture. It's the way someone would go about putting pieces of a website page together.

# The Point of All This
Even if you have NEVER heard of design patterns, they can pop up anywhere. Importing icons from Bootstrap can be considered a Dynamic Import. Design patterns are nice to have if you want to categorize types of code. The thing is, you don't have to actively think about design patterns in order to use them in an effective way. Forgot what in the world a Command Pattern is? That's okay! You don't need to know every pattern by name to be able to create an add space page. It's as simple as considering it a function to be completed.

Design patterns are like a little pop up tutorial at the beginning of a game. You may already know the controls from another game you've played, but the game you're currently playing renamed them and reminded you how everything works. You know how to use your special even if you can't remember the fanciful name the creators gave it. That's design pattens.
